# IDFlipBook v1.19 FINAL

Final refinement release.

### Changes
- Safe built-in RGB + HEX background color picker for InDesign.
- Color selection no longer closes the exporter window.
- New clean 2 × 2 All Pages icon.
- Preserves the stable v1.18 flipbook viewer behavior.

### Recommended export
- PNG
- 600 ppi for general use
- 900 ppi for small text-heavy documents
