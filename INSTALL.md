# Installation

## macOS / Windows

1. Open Adobe InDesign.
2. Choose **Window > Utilities > Scripts**.
3. Expand **User**.
4. Right-click **User** and choose **Reveal in Finder** on macOS or **Reveal in Explorer** on Windows.
5. Copy `IDFlipBook_v1.19.jsx` into the **Scripts Panel** folder.
6. Open an InDesign document.
7. Double-click `IDFlipBook_v1.19.jsx` to export a flipbook.

The exported folder contains `index.html`, page images, viewer assets, and optionally a PDF.
